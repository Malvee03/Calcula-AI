# Calcula AI

Assistente de matemática aplicada a Administração, Economia e Contabilidade.

## O que faz

- Resolve sistemas lineares, equações, derivadas e integrais
- Calcula matemática financeira (juros, VPL, TIR, payback)
- Explica passo a passo, como um professor no quadro
- Salva histórico por usuário
- Suporta modo claro e escuro

### 1. Clone o repositório
bash
git clone https://github.com/SEU_USUARIO/calcula-ai.git
